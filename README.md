# **🤖-Python Voice Assistant**

</div>

"SAT" is a Python-based voice assistant designed to perform everyday tasks through voice commands.
It leverages speech recognition and text-to-speech technologies to provide an interactive and hands-free user experience.

---------

##  ✨ Features

*🎙️ Speech recognition using microphone input

*🔊 Text-to-speech voice responses

*🎵 Play songs and videos on YouTube

*📚 Fetch information from Wikipedia

*⏰ Tell current date and time

*😂 Respond with jokes and fun interactions

*🧠 Simple and extensible command-based logic

-----------

#  🛠️ Technologies Used

-Programming Language: Python

-Libraries & Tools:

-speech_recognition

-pyttsx3

-pywhatkit

-wikipedia

pyjokes
